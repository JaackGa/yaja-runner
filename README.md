# 야자수 러너

야자수와 앨리스가 해변을 달리며 코코넛과 야자나무를 뛰어넘는 모바일용 점프 러너(엔드리스 러너) 게임이에요.

## 하는 법

- 화면을 탭하면 점프, 길게 누르면 더 높이 뛰어요.
- 달린 거리(m)가 늘수록 점점 빨라져요. 최고 기록은 기기에 저장돼요.
- 키보드에서는 Space, 위 방향키, W로 점프해요.

## 캐릭터 능력

| 캐릭터 | 능력 | 설명 |
| --- | --- | --- |
| 야자수 | 더블 점프 | 공중에서 한 번 더 탭하면 다시 뛰어요. |
| 앨리스 | 글라이더 | 점프 후 떨어질 때 꾹 누르면 천천히 활공해요. 한 번 점프에 0.9초까지 쓸 수 있어요. |

## 실행

빌드가 필요 없어요. `index.html` 하나로 되어 있어서 브라우저로 열면 바로 실행돼요. 캐릭터 그림은 파일 안에 포함되어 있어요.
